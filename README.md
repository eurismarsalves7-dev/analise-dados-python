# Análise de Dados com Python

Portfólio de análises exploratórias utilizando Python para transformar dados brutos em **informação útil para decisões**.

## O que o projeto demonstra
- Limpeza e preparação de dados
- Análise exploratória (EDA)
- Estatística descritiva
- Identificação de padrões e outliers
- Visualização de indicadores
- Comunicação dos principais achados

## Stack
Python • Pandas • NumPy • Matplotlib • Seaborn • Jupyter

## Fluxo
```
Dados brutos → Limpeza → EDA → Visualização → Insights → Relatório
```

> Repositório de estudos e portfólio em Ciência de Dados.
